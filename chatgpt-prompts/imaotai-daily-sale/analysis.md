# 内容分析

## 主题

茅台销售方式变革：i茅台从抢购转向日常售卖，让酒真正到达消费者手中。

## 核心观点

1. 过去流通环节囤货、炒作造成的"买不到"，被市场误认为是茅台的稀缺性
2. 价格高 ≠ 真实需求旺盛，相当一部分酒压在经销商和流通环节手里
3. i茅台从抢购转向日常售卖，自营门店面向社会开放
4. 目的：让消费者更容易买到酒，减少中间环节的囤积和炒作
5. 短期可能影响批价、经销商有压力，但渠道空转的繁荣难持续
6. 2027 年度下沙生产结束，未新增基酒产能，给市场留出消化时间
7. 制定年内中期分红方案，赚多少钱、留多少现金、回馈多少股东变得更关键
8. 稳定利润 + 现金流 + 较好分红 = 不错的经营状态

## 关键视觉元素

- **茅台酒瓶**：白色瓶身、红色飘带、红色标签 — 核心识别物
- **手机 App（i茅台）**：抢购状态（闹钟、倒计时、人群推挤）vs 日常售卖状态（店铺、日历、购物袋）
- **囤积纸箱堆**：渠道囤货，画叉号表示要去化
- **消费者火柴人**：开心接到酒瓶，代表真实需求
- **分红元素**：钱袋、硬币向外流出的箭头
- **转变箭头**：连接"抢购 → 日常售卖"两个状态
