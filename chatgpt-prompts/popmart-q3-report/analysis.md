# 内容分析：泡泡玛特三季报

## 主题

泡泡玛特三季报解读——整体收益大幅下滑，但结构比总量更重要：中国市场相对韧性、线下好于线上、新 IP 接棒老 IP、库存压力仍待消化。

## 核心观点

1. **看结构不看总量**：跌多少不是重点，市场间的分化才是重点
2. **中国区韧性强于海外**：高基数下海外降幅远大于中国；去年 Q3 LABUBU 海外集中爆发
3. **线下好于线上**：门店体验和多 IP 展示形成支撑，国内基本盘未随 LABUBU 热度回落而走弱
4. **IP 接棒是关键**：老 IP 回落、星星人 +580.6% 接棒，持续孵化新 IP 决定长期价值
5. **海外暴露运营问题**：供应链与库存管理，存货 61.02 亿、周转 201 天，从扩张转向精细化
6. **展望**：Q4 稳中有升的判断有待实际经营数据验证

## 关键视觉元素

- **盲盒 + 潮玩公仔**：立方盲盒掀盖弹出圆滚滚公仔，最强辨识度意象
- **四个市场的下降条形图**：中国条最短（淡绿高亮），亚太/美洲/欧洲降幅大（粉色）
- **IP 接棒场景**：老 IP 微微低头（-7.5%）→ 新 IP 活力跳跃（+580%），中间接力棒
- **线上 vs 线下**：手机大降幅 vs 小店铺小降幅 + 韧性盾牌
- **纸箱堆叠**：库存 201 天、回落箭头
- **「稳中有升」小旗帜**：Q4 展望
- **手账装饰**：小星星、购物袋、和纸胶带、回形针、问号涂鸦
